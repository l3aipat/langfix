LangFix แก้ข้อความที่พิมพ์ผิดแป้น ไทย/อังกฤษ ให้อัตโนมัติ
เช่น พิมพ์ "l;ylfu" ตอนแป้นเป็นอังกฤษ จะถูกแก้เป็น "สวัสดี" และสลับแป้นให้

ติดตั้ง
1. ลาก LangFix ไปวางในโฟลเดอร์ Applications
2. เปิด LangFix จาก Applications
3. ถ้าขึ้นว่า "LangFix" Not Opened ให้กด Done
   แล้วไปที่ System Settings > Privacy & Security
   เลื่อนลงล่างสุด กด Open Anyway แล้วใส่รหัสผ่านเครื่อง
   จากนั้นเปิด LangFix อีกครั้ง และกด Open Anyway
4. ให้สิทธิ์ Accessibility
   คลิกไอคอน ก/a ที่แถบเมนูด้านบนขวา
   เลือก "Turn on LangFix in Accessibility settings…"
   แล้วเปิดสวิตช์ของ LangFix
5. รอให้ไอคอนเปลี่ยนจาก ก/a ⚠︎ เป็น ก/a แปลว่าพร้อมใช้งาน

เครื่องต้องมีแป้นทั้งภาษาไทย (Thai) และอังกฤษ (ABC หรือ U.S.)
ตั้งได้ที่ System Settings > Keyboard > Input Sources

วิธีใช้
- พิมพ์ตามปกติ ถ้าพิมพ์ผิดแป้น LangFix จะแก้ให้เองตั้งแต่ตัวอักษรที่ 3
- แก้ผิด ให้กด Delete ทันที ข้อความเดิมจะกลับมา และ LangFix จะจำคำนั้นไว้ไม่แก้อีก
- แปลงข้อความเก่า ให้เลือกข้อความแล้วกด Option+Shift+Space
- ปิดในบางแอป ให้เปิดแอปนั้น แล้วเลือก "Off in …" จากเมนู ก/a
- ตั้งค่าอื่นๆ เลือก Settings… จากเมนู ก/a

อัปเดตเป็นเวอร์ชันใหม่
ลากตัวใหม่ไปทับใน Applications แล้วทำข้อ 3 และข้อ 4 ใหม่
ถ้าสวิตช์ Accessibility ของ LangFix เปิดอยู่แล้วแต่ไอคอนยังเป็น ก/a ⚠︎
ให้เลือก LangFix ในรายการ กดปุ่ม − แล้วกด + เพิ่ม LangFix กลับเข้าไป
